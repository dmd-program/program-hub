# Interactive Media Developer

The Interactive Media Developer pathway prepares students to design and develop interactive digital experiences using modern web technologies, programming languages, and design principles.

## Core Skills

- Front-end web development (HTML, CSS, JavaScript)
- Interactive design and user experience
- Responsive and mobile-first development
- API integration and data visualization
- Version control and collaboration tools

## Key Courses

This pathway emphasizes technical skills combined with design thinking:

### Foundation Courses
- **IST 140** - Introduction to Application Development
- **IST 261** - Application Development Design Studio I
- **DART 206** - Interactivity and Computation

### Advanced Development
- **IST 311** - Emerging Technology for Designers
- **IST 331** - Intermediate Interactive Media Development
- **IST 361** - Advanced Interactive Media Development

### Design & Theory
- **DART 200** - Digital Multimedia Design Foundations
- **COMM 282** - Web Design and Development
- **GD 100** - Digital Design Foundations

## Career Opportunities

Graduates are prepared for careers as:
- Front-end Developer
- UX/UI Developer
- Interactive Designer
- Web Developer
- Digital Product Designer
- Creative Technologist

## Projects & Portfolio

Students build a portfolio showcasing:
- Responsive websites and web applications
- Interactive data visualizations
- Mobile-first interfaces
- API-driven applications
- Progressive web apps

## Industry Tools

- Modern JavaScript frameworks (React, Vue, Angular)
- CSS preprocessors and frameworks
- Git and GitHub for version control
- Design tools (Figma, Adobe XD)
- Development environments and build tools
